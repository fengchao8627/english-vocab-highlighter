Privacy Policy — 英语生词高亮助手 (Vocab Highlighter)

Effective date: 2026-10-24 | Version: 1.1.3 | 生效日期：2026-10-24 | 版本：1.1.3

This policy applies to the browser extension “英语生词高亮助手 - Vocab Highlighter” (version 1.1.3), distributed via the Chrome Web Store and Microsoft Edge Add-ons.
本政策适用于浏览器插件「英语生词高亮助手 - Vocab Highlighter」（1.1.3 版），通过 Chrome Web Store 和 Microsoft Edge Add-ons 分发。

Contact / 联系方式：via the GitHub repository issue tracker at https://github.com/fengchao8627/english-vocab-highlighter

1. No account, no analytics, no ads / 无账号、无统计、无广告

The extension does not require an account. It does not use analytics, tracking, advertising SDKs, or fingerprinting, and it does not sell or share your personal data with data brokers.
插件不需要注册账号，不使用统计、追踪、广告 SDK 或设备指纹，不向数据中介出售或分享你的个人数据。

2. Data stored locally / 本地存储的数据

The following data is stored only in your browser’s local extension storage (chrome.storage.local) on your own device:
以下数据只存在你自己设备的浏览器本地扩展存储（chrome.storage.local）中：

  • Your settings: English level, auto-learn threshold, API base URL, model, and API key.
    你的设置：英语级别、自动学会阈值、API 地址、模型和 API Key。
  • Lookup cache: words you have looked up and their explanations, to avoid repeated lookups.
    查词缓存：你查过的词和释义，用于避免重复查询。
  • Learned words and your vocabulary book: words you marked as known, and words you added to your vocabulary book.
    已学会词和生词本：你标记为已学会的词、加入生词本的词。

The developer does not operate a server that receives or stores this local data. You can delete the caches from the extension’s settings page, and uninstalling the extension removes its local storage subject to your browser’s behavior.
开发者没有接收或存储这些本地数据的服务器。你可以在插件设置页清空缓存；卸载插件后，其本地存储会随浏览器行为清除。

3. Data sent to third parties — only the word or phrase you ask about / 对外发送的数据：只有你主动查询的词句

When you hover over a highlighted word or use the selection-explanation feature, the extension sends only that word, phrase, or sentence to the API service you configured, so it can return a pronunciation and explanation:
当你悬停标黄的词或使用划词解释时，插件只会把那一个词、词组或句子发给你自己配置的 API 服务，用于返回音标和释义：

  • Default: the DeepSeek API (https://api.deepseek.com), using the API key you entered, if any. Default model: deepseek-flash.
    默认：DeepSeek 接口（https://api.deepseek.com），使用你填入的 Key（如有）。默认模型：deepseek-flash。
  • If you change the settings, requests go to the OpenAI-compatible API address you entered instead.
    如果你改了设置，请求会发往你填入的 OpenAI 兼容接口地址。
  • If no API key is configured, the free dictionary fallback (https://api.dictionaryapi.dev) is used for the single word you looked up, and it returns an English definition only, without Chinese.
    如果未配置 Key，会用免费词典回退接口（https://api.dictionaryapi.dev）查你悬停的那一个词，只返回英文释义、没有中文。

The extension does not send your full page content, browsing history, other tabs’ content, or your locally stored vocabulary book to any third party. Your API key is stored only in your browser and is sent only to the API address you configured, as part of that lookup request.
插件不会把整页内容、浏览历史、其他标签页内容或你的生词本发给任何第三方。你的 API Key 只存在你的浏览器里，只在查词请求中发往你配置的那个接口地址。

Third-party services have their own privacy policies, which govern how they handle the word or phrase sent to them. Please review the policy of the API service you choose.
第三方服务有各自的隐私政策，你查询的词句如何被处理以你所选服务的规定为准，请自行查看。

4. Permissions — why each one is needed / 权限说明

  • storage: to save the local settings, caches, learned words, and vocabulary book described above.
    storage：保存上述本地设置、缓存、已学会词和生词本。
  • activeTab: to work on the tab you are currently interacting with.
    activeTab：在你当前交互的标签页上工作。
  • Host access to web pages: the extension’s core function is to highlight words on any English web page you open, so it must be able to read page text locally to decide which words exceed your level. Page text is processed locally; it is not uploaded wholesale.
    网页访问权限：插件的核心功能是在你打开的任意英文网页上标词，因此需要在本地读取页面文本判断哪些词超出你的级别；页面文本只在本地处理，不会整页上传。
  • Host access to the API addresses above: to fetch explanations from the service you configured (or the dictionary fallback).
    接口地址访问权限：向你配置的服务（或词典回退接口）请求释义。

5. Changes / 政策变更

If this policy changes in a material way, the updated version will be published at the same URL as this policy, with a new effective date. Continued use of the extension after a change means you accept the updated policy.
如本政策有实质变更，新版将发布在同一链接并更新生效日期；变更后继续使用插件即表示接受新版政策。
