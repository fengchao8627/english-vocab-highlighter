1. API 设置（地址、模型、Key 都可改）

默认是 DeepSeek，也可以换成任何 OpenAI 格式的接口：OpenAI、硅基流动、Kimi、通义、本地 Ollama 兼容服务等。Key 只存在你浏览器本地存储里，查词时由插件后台直连你填的地址，不经过任何第三方服务器。不填 Key 也能用（走免费词典，只有音标+英文释义，没有中文）。

填 Base 即可，如 https://api.deepseek.com、https://api.openai.com/v1、https://api.siliconflow.cn/v1；填完整地址 .../chat/completions 也可以，插件会自动归一化。

默认 deepseek-flash；换服务商时填对应模型名，如 OpenAI 的 gpt-4o-mini、DeepSeek 官方的 deepseek-chat。换模型后已缓存的释义不会自动失效，如需重新查请点下面「清空释义缓存」。

DeepSeek 去 platform.deepseek.com → API Keys 创建；其他服务商去各自控制台创建。

1b. 划词 / 划句解释

在任意网页上用鼠标选中英文（一个词、词组或一句话），旁边会弹出「✦ 解释选区」按钮，点开看中文翻译 + 结构讲解 + 难词拆解。单个词会直接走查词结果。选区解释结果同样本地缓存。

3. 分级说明

小学≈掌握最常用 800 词 / 初中≈1600 / 高中≈3500 / 四级≈4500 / 六级≈6000 / 考研专八≈8000。插件按词频表判断：你所选级别以内的词默认会、以外标黄。专有名词（大写开头且不在词频表内）自动跳过，代码块、输入框不标记。
