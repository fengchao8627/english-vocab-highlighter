> 按你的英语水平，把英文网页里的生词自动标黄；鼠标悬停看音标和释义；你没查看的词，默认你已经会了，下次不再标记。

读英文网页时，最打断节奏的不是完全看不懂，而是不断停下来查词。这个插件想解决的是一件小事：**只提醒你真正可能不会的词，并且越用越懂你。**

## ✨ 功能

- **按水平分级标黄** — 下拉选择你的水平（小学 / 初中 / 高中 / 大学四级 / 大学六级 / 考研·专八），只有超出你水平的词才会被标黄
- **悬停即查词** — 鼠标放上去弹出释义卡片：音标、词性、中文释义、英文释义、例句及翻译
- **划词 / 划句解释** — 在网页上选中一个词、词组或一句话，旁边弹出「✦ 解释选区」，点开看中文翻译 + 结构讲解 + 难词拆解（单个词直接走查词结果）
- **API 灵活配置** — 地址、模型、Key 都可在设置页改：默认 DeepSeek，也支持任何 OpenAI 格式接口（OpenAI、硅基流动、Kimi、通义、本地兼容服务等），填 Base URL 即可，填完整 `/chat/completions` 地址也可自动识别；默认模型为 `deepseek-flash`
- **隐式学习（核心设计）** — 一个词被标黄后，如果你在多个不同页面反复见到它、却从未悬停查看，插件就推断你其实认识它，自动记为「已学会」，以后不再打扰你
- **生词本** — 真不会的词可以一键加入生词本，之后会一直被标黄，直到你手动点「我会了」
- **本地缓存** — 查过的词会缓存在本地，重复悬停不重复调用 API，不重复花钱
- **注重隐私** — 不设服务器、不收集数据。水平、生词本、已学会词表、API Key 全部只存在你浏览器本地

## 🧠 它是怎么判断「你会了」的？

```
生词被标黄
  ├─ 你悬停查看了释义 ──────────→ 认为你还不会，继续标记
  │    ├─ 点「✓ 我会了」──────────→ 立即记为已学会，取消高亮
  │    └─ 点「＋ 生词本」──────────→ 一直标记，直到你点「我会了」
  │
  └─ 你没查看（在 1 个页面出现）─→ 观察计数 +1（按不同页面计，刷新不重复计）
       └─ 累计达到阈值（默认 3 个不同页面）→ 自动记为已学会，不再标记
```

阈值可在插件弹窗里调整（1–6 次）。这个设计避免了两种误判：同一篇文章里一个词出现很多次，不会因为这一篇就被判定学会；偶尔跳过一次，也不会立刻被当成已经掌握。

## 🚀 快速开始

### 安装（加载已解压的扩展程序）

1. 下载本仓库（`git clone` 或下载 ZIP 并解压）
2. 打开浏览器扩展页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 打开右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本项目文件夹
5. 点击浏览器工具栏的插件图标，在下拉框里选择你的英语水平，刷新任意英文网页即可生效

> 目前尚未上架 Chrome 应用商店，正式开源发布后会补充商店安装方式。

### 配置 API（推荐，默认 DeepSeek）

没有 API Key 也能用（走免费词典，只有音标 + 英文释义），但**中文释义和划句解释需要 API**：

1. 默认用 DeepSeek：前往 [platform.deepseek.com](https://platform.deepseek.com) 注册，进入「API Keys」创建一个 Key
2. 点击插件图标 →「设置 API 地址 / 模型 / Key / 词表」
3. 保持 Base URL 为 `https://api.deepseek.com`、模型为 `deepseek-flash`（默认），粘贴以 `sk-` 开头的 Key，保存后点击「测试查词」验证
4. 换服务商时只需改三项：Base URL（如 `https://api.openai.com/v1`）、模型（如 `gpt-4o-mini`）、对应 Key，保存后点「测试查词」和「测试划句解释」验证
5. 回到英文网页，悬停任意标黄单词看释义，或直接划选一段话点「✦ 解释选区」

查词成本很低（单次约几厘钱），且结果会本地缓存，同一个词不会重复计费。

## ⚙️ 分级说明

| 水平 | 假定已掌握词汇量 | 说明 |
|---|---|---|
| 小学 | 约 800 | 最常用核心词 |
| 初中 | 约 1,600 | 中考范围 |
| 高中 | 约 3,500 | 高考范围（默认） |
| 大学四级 CET-4 | 约 4,500 | 四级范围 |
| 大学六级 CET-6 | 约 6,000 | 六级范围 |
| 考研 / 专八 | 约 8,000 | 进阶阅读 |

分级基于词频表（Google Books 词频前 10,000 词）近似对应国内课程词汇量，并做了基础词形还原（如 `knows`、`looked` 不会被误判为生词）。专有名词、代码块、输入框中的内容不会被标记。

> 说明：这不是官方课标词表的逐词对齐，个别单词的难度归类可能与教材顺序略有出入。你认为不该标的词，悬停后点一次「我会了」即可，插件会永久记住。

## 🔒 隐私

- **无服务器**：本插件没有后端，不收集、不上传你的浏览记录和词表
- **本地存储**：所有数据保存在浏览器 `chrome.storage.local` 中
- **直连官方接口**：查词请求由你的浏览器直接发往 DeepSeek 官方接口（或免费词典接口），不经过任何第三方中转
- **词表可导出**：设置页支持导出 / 导入词表 JSON，方便备份和迁移

## 📁 项目结构

```
english-vocab-highlighter/
├── manifest.json        # Manifest V3 配置
├── background.js        # Service Worker：调用 DeepSeek / 免费词典、管理缓存
├── content.js           # 页面扫描、生词标黄、悬停卡片、隐式学习结算
├── content.css          # 高亮与释义卡片样式
├── popup.html / .js     # 工具栏弹窗：开关、水平下拉框、阈值、统计
├── options.html / .js   # 设置页：API Key、已学会 / 生词本管理、导入导出
├── data/
│   └── wordlists.js     # 词频表（前 10,000）与分级阈值
└── icons/               # 插件图标（16 / 48 / 128）
```

无构建步骤，原生 JavaScript，克隆下来即可加载运行。
